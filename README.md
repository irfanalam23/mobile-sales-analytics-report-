1. 📱 Mobile Sales Analytics Report

2. 📖 Overview  
This project showcases an **interactive Power BI dashboard** developed to analyze mobile sales data and generate meaningful business insights. The dashboard provides visual analysis of sales performance, top-selling brands, customer trends, and regional performance.

3. 🛠️ Tools Used  
- Power BI  
- Power Query  
- DAX  
- Excel / CSV Dataset  

4. 📊 Key Features  
- Sales performance analysis  
- Brand and model-wise insights  
- Regional sales comparison  
- Interactive filters and visualizations  
- KPI tracking and trend analysis  

5. 🎯 Project Goal  
To transform raw mobile sales data into an interactive and insightful dashboard for better business decision-making.
